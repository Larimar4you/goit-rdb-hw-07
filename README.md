# goit-rdb-hw-07

Домашнє завдання до теми 7: **Додаткові вбудовані SQL-функції. Робота з часом**

## Завдання

1. Використання `YEAR()`, `MONTH()`, `DAY()` для отримання частин дати.
2. Додавання одного дня до дати за допомогою `DATE_ADD()`.
3. Перетворення дати на Unix timestamp за допомогою `UNIX_TIMESTAMP()`.
4. Підрахунок замовлень за визначений період із використанням `COUNT()` та `BETWEEN`.
5. Створення JSON-об'єкта за допомогою `JSON_OBJECT()`.

## Технології

- MySQL
- MySQL Workbench

## Файли

- `hw07.sql` — SQL-запити до всіх п'яти завдань.
- `p1_` – `p5_` — скриншоти запитів і результатів виконання.
